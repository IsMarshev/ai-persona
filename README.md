# Аркадий — рабочее место ИИ-персонажа
Один ИИ-персонаж с характером, голосом и собственной жизнью друг [Гарика](https://github.com/s1kiri/ai-persona/tree/main). Учебный проект
трека 2 AI Persona Lab, осень 2026.

Аркадий Кедров, 54 года, бывший инженер, который двадцать лет искал
пришельцев и нашёл Гарика в соседней шаурмичной. Переделывает собственное
тело, спорит со своей цифровой копией и боится потратить жизнь раньше,
чем поймёт, как её продлить. Друг Гарика, со своей инициативой и характером.

Проект подготовлен по первому заданию AI Persona Lab, трек 2.
Основа — [agent-workplace](https://github.com/3ndetz/agent-workplace).

## Что открыть сначала

- `agent/arkady/PERSONA.md` — полный канон и поведение Аркадия.
- `prompts/arkady-chat-clean.md` — готовый промпт для нового чата без мата.
- `prompts/arkady-chat-free.md` — личная беседа с разрешённым матом.
- `docs/homework-1.md` — черновик сдачи: промпт от первого лица, место для
  результатов проверки, короткий план и правильный хештег.
- `docs/example-dialogues.md` — авторские иллюстрации, не результаты запуска.
- `docs/pair-canon.md` — знакомство и отношения с Гариком.
- `integration/garik-addendum.md` — необязательное дополнение в его проект,
  чтобы второй агент знал ту же историю знакомства.

## Быстрая проверка

Нужен Python 3.9+; внешние Python-пакеты не требуются. Bash нужен только
для локальных скриптов очереди и памяти. Все команды выполняй из корня.

```bash
python3 tools/check.py
python3 tools/compose_persona.py arkady
python3 tools/compose_persona.py arkady --register free-chat
python3 tools/compose_session.py arkady
```

Для общения в обычном чатботе скопируй весь `prompts/arkady-chat-clean.md`
в системную инструкцию, если интерфейс это позволяет, либо первым сообщением
в новый чат. Затем пройди `docs/test-cases.md`. Чистый чат не сохраняет
эти файлы памяти автоматически.

Сборка свежих готовых промптов после правки PERSONA.md:

```bash
python3 tools/compose_persona.py arkady --register non-obscene-chat > prompts/arkady-chat-clean.md
python3 tools/compose_persona.py arkady --register free-chat > prompts/arkady-chat-free.md
python3 tools/compose_session.py arkady > prompts/arkady-session.md
```

Последний файл включает память текущего состояния, цели и правила рабочего
места. Он предназначен для агента с файловыми инструментами. В обычном чате
используй два первых файла. В session-сборке entity-заметки читаются агентом
по необходимости, а не вставляются все без разбора.

## Локальные действия

```bash
export AGENT_NAME=arkady
bash agent/scripts/say.sh operator 'Нужен адаптер для чтения сообщений.'
bash agent/scripts/remember.sh garik 'FICTION SESSION: discussed the bench; no new consent given.'
bash agent/scripts/sleep.sh 30
bash agent/scripts/ticket.sh 'Нужен Telegram-адаптер для доставки сообщений из outbox.'
```

`say.sh` добавляет локальную запись в очередь. `remember.sh` добавляет
датированное событие; обратные ссылки дополняются отдельно. `sleep.sh`
пишет желаемый интервал, а `ticket.sh` сохраняет заявку внутри рабочего места.
Эти действия сами по себе не отправляют сообщения и не запускают таймер.

## Статус

Готовы личность, канон пары, стартовая память, цели, два регистра, сборка
промптов, сценарии проверки, черновик ДЗ и план. Проверена техническая
целостность файлов и сборка промптов. Реальный внешний диалог по этому
пакету ещё не записан: его ответы нужно вставить в раздел 2 ДЗ.

Как и исходный шаблон, пакет не содержит runtime, планировщик, модельный
API, Telegram/Minecraft-адаптер, TTS или аватар. Этапы их подключения
описаны в `docs/development-plan.md`. Публикация своего репозитория и
сдача в тему «Прогресс» остаются действиями владельца.
